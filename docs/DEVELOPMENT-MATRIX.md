## 新增约束与功能对照

- 首页整体布局与 Lucid 风格保持，允许调整重复入口。
- 更新图标按提供的圆弧 / 实心箭头参考图重新手绘；1.0.1节点排序与落地操作使用Lucide矢量，未引入Surge或morphicons素材。

- 低内存列为验收目标：Debug 前台基线主进程 PSS 约 88 MiB、服务约 134 MiB；打开关于页后主进程约 123 MiB。已将版本 / 密钥 API 移到服务以避免 UI 进程加载第二份 Go 内核，并削减无关页面轮询，新样本主进程约91MiB、后台约111MiB；采样热度不同，不据此声称固定降低比例。
- 新增真实配置验证：停机 28 组 / 58 个去重名称，运行 27 组（5 自动组）、27 条规则、外部 A / AAAA、测速与 25 个提供器更新通过。真实 HTTPS 已通过。机场订阅开关影响更新结果，真实订阅与后台更新由用户后续验收，本轮不再请求机场接口。
- 文件导入 / 导出 / 重命名 / 无效编辑回滚、Geo 无效文件拒绝与两种 age 密钥测试通过；VPN 四栈 / IPv6 / 分应用 / 代理模式及服务死亡恢复共 3 项回归已通过。
