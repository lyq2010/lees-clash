## 1.0.2：策略延迟显示（2026-10-28）

策略组摘要增加当前所选节点的 `delay`，通过 Binder Parcel 保留；嵌套选择继续查找实际节点，摘要仍不返回节点列表。节点与摘要均读取最近完成的 URL 检测历史：没有历史为0、失败为65535，避免把从未测速误标成超时；多个检测网址采用最近完成的记录。停止服务时不显示测速结果。

列表、卡片、网格共用延迟显示：1–299ms绿色、300–599ms黄色、600ms及以上红色，失败显示红色“超时”，未测速留空。现有测速通过节点实际拨号并向配置检测网址发送 HTTP HEAD；开启 `unified-delay` 时优先使用第二次请求计时，不是下载带宽测试。

验证：ARM64 Alpha Debug及测试APK构建成功，JVM25项通过；Go `native/tunnel`、`native/diagnostics`、`native/preview` 回归通过。专用API35 ARM64模拟器（1080×2340 / 440dpi）3项通过：Binder Parcel往返、三种布局浅深色的299 / 300 / 599 / 600ms边界与失败 / 未测速 / 停机状态、既有布局持久化与导航 / 网格等高。模拟器默认320dp宽时，既有网格测试假设两列而失败；按其手机测试尺寸复跑通过，产品窄屏单列行为未改。本轮未执行正式签名Release或真机专项验收。

### 覆写语义

- `global-client-fingerprint`已被当前内核移除；模型仍读旧值，界面标停用并仅允许清空。节点使用`client-fingerprint`。
- 会话覆写在服务每次启停时清除，优先级为原配置→持久覆写→会话覆写。
- Android必须保留内部DNS；关闭DNS会启用应用默认并附加系统DNS，界面已有说明。
- 空集合与未覆写不同：列表可显式清空，hosts空映射不删除原配置键，同名键按合并语义覆盖。
- TLS测试信任仅限回环临时自签名连接，不改系统信任；NTP的write-to-system=true只做解析，不为测试改变设备系统权限。
