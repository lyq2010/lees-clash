# 界面与品牌规范

## 首页配置选择

配置入口保持在左上角，启动控件独立位于右侧。直接显示单行配置名称和矢量下拉箭头，不添加“当前配置”等辅助标题，不再使用字体字符作为箭头。完整配置名称同时提供给无障碍服务。

配置入口与启动控件至少保持 12dp 间距，名称不能挤入按钮区域；窄屏与大字体下对过长名称使用省略号，名称始终保持单行。点按配置入口进入配置管理与选择页，可查看完整名称。

## 导航与操作

保留三页主导航及首页原有布局，仅收敛工具 / 更多中的重复入口：

| 主页面 | 功能 |
|---|---|
| 首页 | 原有“通用 / 网络 / 覆写”标签及彩色卡片，配置选择、运行与常用快捷入口 |
| 工具 | 连接、DNS、统计、日志、规则检索 |
| 更多 | 应用设置、VPN 与网络、覆写、资源提供器、Geo 数据、加密密钥、帮助与关于 |

- 首页保留原有布局、卡片与快捷操作，不以入口去重为由重排首页。
- 工具页移除配置管理、代理策略与资源提供器的重复项；更多页移除单独的分应用代理项，该功能仍可从首页网络标签或 VPN 与网络进入。
- 配置列表只保留右上角导入入口；每条订阅直接提供更新按钮，与编辑入口分开。
- 导入期间显示下载 / 资源 / 验证阶段并禁止重复提交；成功后返回配置列表，新条目置顶并滚动可见。失败保留表单与错误，允许重试。
- 手动更新等待真实完成，列表展示“更新中”并阻止重复请求；编辑保存完成后返回上级。
- 主要写操作使用统一进行中 / 成功 / 失败反馈。后台刷新不能清掉用户操作错误；开关等即时控件以实际状态变化反馈。
- 从独立表单 Activity 返回时保留系统完成提示，避免页面关闭带走成功反馈。

## 停止状态浏览

停止代理后仍从所选配置和已下载的提供器缓存读取策略组、节点与规则，不启动监听端口或发起下载。手动策略可保存预选；自动策略的当前结果与节点延迟在运行后显示。规则页明确区分“配置规则”和运行时“生效规则”。

本地预览只复用不可变解析结果；配置或缓存文件的路径、大小、修改时间发生变化时失效。DNS 查询、测速与运行中资源更新仍需要启动服务，并给出明确说明。

## 动效

动效用于提示操作与层级，不增加持续播放的装饰动画：

| 场景 | 行为 |
|---|---|
| 顶层导航 | 约 160ms 淡入淡出 |
| 进入详情、返回上级 | 约 230ms，小距离横移与透明度变化，返回方向对称 |
| 首页二级标签 | 约 160ms 淡入淡出，高亮与下划线颜色同步过渡 |
| 列表与按钮按压 | 90ms 透明度反馈；胶囊和卡片按钮额外缩至 97%，释放后无回弹恢复 |
| 开关 | 180ms 滑块位移与轨道颜色过渡 |
| 模式选择、列表选中标记 | 100–180ms 高亮、勾选和说明展开收起 |
| 启动控件 | 状态文字交叉淡入，宽度与禁用颜色平滑更新 |

页面转场只作用于显示层，目标路由的数据加载由单独的生命周期协程执行。过渡期间可以继续输入；不对实时流量数字逐秒执行位移或重排动画。使用 Compose 标准动画时钟，遵守 Android 系统动画时长设置。实现方式参考 [Android 官方动画指南](https://developer.android.com/develop/ui/compose/animation/composables-modifiers)。

## 独立图标

标识采用白色猫形轮廓与三道递增信号负形，蓝色至青绿色背景。参考 Clash 的猫形识别与 Surge 的信号节奏，路径在本工程重新绘制，没有直接使用两者的图标素材。

- [SVG 母版](brand/icon.svg)，构建使用工程内自适应图标资源。
- 桌面使用自适应前景 / 背景，并提供单色主题图标；首页使用相同几何路径的紧凑版本。
- 通知、磁贴与文件提供器使用同一标识的单色版本。
- 图形关键部分位于自适应图标安全区域；被替代的旧位图文件已按I03授权清理。

参考来源：[CMFA 官方仓库](https://github.com/MetaCubeX/ClashMetaForAndroid)、[Surge 官方 App Store 页面](https://apps.apple.com/us/app/surge-5/id1442620678)。图标为本应用的独立身份，不表示与参考产品存在官方关联。

## 反馈层级（2026-10-27）

- 配置标题的三角紧跟文字，短名称不撑开；长名称仍为单行省略，右侧运行控件保持独立。
- 成功 / 复制 / 切换等已完成操作使用应用内底部短 Toast，约4秒自动消失，不遮挡底栏；可访问性使用 polite live region。
- 超过300ms的操作显示顶部进度浮层，快速操作不闪烁；错误顶部 Alert 不自动消失，可关闭，长错误通过详情 Modal 完整读取。提示均不改变正文布局。
- 删除 / 清空 / 断开连接 / 放弃修改用明确二次确认，表单错误继续就地显示；编辑仍使用现有完整表单。移动端不为套用组件名增加 Tooltip、长按提示或重复 Drawer。
