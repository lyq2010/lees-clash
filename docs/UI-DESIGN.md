# 界面与品牌规范

## 首页配置选择

配置入口保持在左上角，启动控件独立位于右侧。直接显示单行配置名称和矢量下拉箭头，不添加“当前配置”等辅助标题，不再使用字体字符作为箭头。完整配置名称同时提供给无障碍服务。

配置入口与启动控件至少保持 12dp 间距，名称不能挤入按钮区域；窄屏与大字体下对过长名称使用省略号，名称始终保持单行。点按配置入口进入配置管理与选择页，可查看完整名称。

## 动效

动效用于提示操作与层级，不增加持续播放的装饰动画：

| 场景 | 行为 |
|---|---|
| 顶层导航、首页二级标签 | 约 160ms 淡入淡出 |
| 进入详情、返回上级 | 约 230ms，小距离横移与透明度变化，返回方向对称 |
| 列表与按钮按压 | 90ms 透明度反馈；胶囊和卡片按钮额外缩至 97%，释放后无回弹恢复 |
| 开关 | 180ms 滑块位移与轨道颜色过渡 |
| 模式选择、列表选中标记 | 100–180ms 高亮、勾选和说明展开收起 |
| 启动控件 | 状态文字交叉淡入，宽度与禁用颜色平滑更新 |

页面转场只作用于显示层，目标路由的数据加载由单独的生命周期协程执行。过渡期间可以继续输入；不对实时流量数字逐秒执行位移或重排动画。使用 Compose 标准动画时钟，遵守 Android 系统动画时长设置。实现方式参考 [Android 官方动画指南](https://developer.android.com/develop/ui/compose/animation/composables-modifiers)。

## 独立图标

标识采用白色猫形轮廓与三道递增信号负形，蓝色至青绿色背景。参考 Clash 的猫形识别与 Surge 的信号节奏，路径在本工程重新绘制，没有直接使用两者的图标素材。

- [SVG 母版](brand/icon.svg) 与 [PNG 预览](brand/icon-preview.png)。
- 桌面使用自适应前景 / 背景，并提供单色主题图标；首页使用相同几何路径的紧凑版本。
- 通知、磁贴与文件提供器使用同一标识的单色版本。
- 图形关键部分位于自适应图标安全区域；旧位图文件保留等待精确清理，不用于 API 26 及以上的活动桌面图标。

参考来源：[CMFA 官方仓库](https://github.com/MetaCubeX/ClashMetaForAndroid)、[Surge 官方 App Store 页面](https://apps.apple.com/us/app/surge-5/id1442620678)。图标为本应用的独立身份，不表示与参考产品存在官方关联。
